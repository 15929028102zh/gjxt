## 问题定位
- 月检复查弹窗使用了不匹配的字段，导致“问题信息”与图片不完整或不显示：
  - 问题图片取自 `problemImageUrls`，而月检实体字段为 `photos`（admin/src/views/inspection/monthly/components/ReviewDialog.vue:249-257）。
  - 图片上传成功处理仅读取 `response.url`，与统一上传返回结构不一致，应读取 `response.data.filePath` 或 `response.data.url`（admin/src/views/inspection/monthly/components/ReviewDialog.vue:343-347）。
  - “问题信息”区展示 `responsiblePerson/responsibleUnit` 等字段，月检记录多以 `departmentName/responsibilityName/issueName/qualityName` 表示，导致信息不全或为空（admin/src/views/inspection/monthly/components/ReviewDialog.vue:12-31）。
- 复查提交数据未统一构造图片 URL，存在服务端解析不一致风险（期望以逗号拼接的字符串）。
- 周检复查弹窗整体逻辑正确，采用统一的图片解析与上传路径转换；月检需对齐（参见 admin/src/views/inspection/weekly/components/ReviewDialog.vue:267-277）。

## 修改方案
1. 月检复查弹窗数据回写与展示完善
- 在打开弹窗时通过 `getById` 获取完整详情，新增 `detailData`/或直接使用 `form` 承载回写数据（admin/src/views/inspection/monthly/components/ReviewDialog.vue:271-312）。
- “问题信息”区改为显示以下字段：`taskNo、inspectionTime、departmentName、responsibilityName、issueName、qualityName、problemDescription、location、inspector、rectificationDeadline`。
- 问题图片改为使用 `parseImageUrls(detailData.photos)`；整改图片使用 `parseImageUrls(detailData.rectificationImages)`。

2. 复查描述与图片录入
- 保留现有 `reviewSuggestion`、`reviewEffect` 必填校验（admin/src/views/inspection/monthly/components/ReviewDialog.vue:239-246）。
- 统一图片上传成功逻辑：读取 `response.data.filePath || response.data.url`，并通过 `convertToHttpUrl` 转换后推入 `form.reviewImages`；移除不兼容的 `response.url` 读取（admin/src/views/inspection/monthly/components/ReviewDialog.vue:343-347）。
- 构造提交的 `reviewImages` 为逗号分隔字符串（admin/src/views/inspection/monthly/components/ReviewDialog.vue:377-383）。

3. 提交行为与服务端接口对齐
- 调用 `monthlyRecordApi.confirmReview(id, { reviewSuggestion, reviewEffect, reviewImages })`，不额外传递月检不需要的状态字段；状态由后端更新为“已复查”。
- 保持成功后关闭弹窗并刷新列表（admin/src/views/inspection/monthly/index.vue:547-551）。

4. 统一图片解析/显示策略
- 引入并使用 `parseImageUrls` 与 `convertToHttpUrl` 以兼容 JSON 字符串/逗号串/相对路径三种后端返回形态（admin/src/config/api.js:37-99）。
- 对齐周检复查弹窗的图片列表构造方式，避免手动维护 URL 与文件列表示例不一致（参照 admin/src/views/inspection/weekly/components/ReviewDialog.vue:267-277）。

## 验证方法
- 打开“月检记录录入”页面（admin/src/views/inspection/monthly/index.vue），选取状态为“已整改”的记录，点击“确认复查”。
- 检查弹窗：
  - 问题信息字段是否完整且正确。
  - 问题/整改图片是否正确展示。
  - 上传 1-3 张复查图片是否均能显示并提交；失败提示是否友好。
- 填写复查建议与复查效果后提交：
  - 列表状态更新为“已复查”。
  - 详情弹窗（ViewDialog）中复查信息与复查图片是否正确显示。
