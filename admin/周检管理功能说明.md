# 周检管理功能说明

## 功能概述
在web端新增了完整的周检管理功能，包括周检记录录入、确认整改、确认复查等核心功能，功能设计与移动端保持一致。

## 菜单结构
```
周检管理
└── 周检记录录入
```

## 主要功能

### 1. 周检记录录入页面
**访问路径**: `/inspection/weekly`

**页面功能**:
- 记录列表展示（表格形式）
- 搜索功能（问题描述、责任人、状态）
- 新增周检记录
- 批量删除
- 行级操作（查看、确认整改、确认复查、删除）

**状态说明**:
- 待整改（橙色标签）
- 已整改（绿色标签）  
- 已复查（蓝色标签）

### 2. 新增周检记录弹窗
**触发方式**: 点击"新增周检记录"按钮

**功能特性**:
- 功能同移动端add.uvue页面
- 支持图片上传（最多3张，JPG/PNG格式，2MB以内）
- 表单验证
- 字典数据下拉选择（性质界定、专业、考核情况等）
- 人员选择（检查人、组长、副组长等）
- 部门选择
- 日期时间选择

**必填字段**:
- 问题描述
- 责任单位
- 责任人
- 专业
- 检查人
- 所属部门
- 整改期限

### 3. 确认整改弹窗
**触发方式**: 点击行级"确认整改"按钮（仅待整改状态可操作）

**功能特性**:
- 功能同移动端detail.uvue页面的整改功能
- 显示问题基本信息
- 可修改性质界定、专业、所属部门
- 填写整改效果描述（必填）
- 上传整改图片
- 选择整改状态

### 4. 确认复查弹窗
**触发方式**: 点击行级"确认复查"按钮（仅已整改状态可操作）

**功能特性**:
- 功能同移动端review.uvue页面
- 显示问题信息和整改情况
- 选择复查结果（通过/不通过）
- 选择复查人
- 填写复查备注（必填）
- 上传复查图片

### 5. 查看详情弹窗
**触发方式**: 点击行级"查看"按钮

**功能特性**:
- 显示完整的记录信息
- 根据状态显示对应的流程信息
- 图片预览功能

## 使用流程

### 典型工作流程
1. **新增记录**: 点击"新增周检记录" → 填写表单 → 上传问题图片 → 保存
2. **整改处理**: 选择待整改记录 → 点击"确认整改" → 填写整改信息 → 上传整改图片 → 确认
3. **复查验收**: 选择已整改记录 → 点击"确认复查" → 填写复查结果 → 上传复查图片 → 确认

### 数据流转
```
待整改 → 已整改 → 已复查
  ↑        ↑        ↑
新增    确认整改   确认复查
```

## 注意事项

1. **权限控制**: 请确保登录用户有相应的操作权限
2. **图片上传**: 图片大小限制2MB，格式限制JPG/PNG
3. **数据验证**: 必填字段均有前端验证
4. **状态控制**: 操作按钮根据记录状态动态启用/禁用
5. **响应式设计**: 页面支持不同屏幕尺寸
