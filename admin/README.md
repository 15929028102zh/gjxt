# 工业巡检系统 - 后台管理

基于 Vue 3 + Element Plus 的现代化后台管理系统。

## 功能特性

- 🎯 **系统设置**：完整的系统配置管理
- 👥 **用户管理**：用户增删改查、状态管理、密码重置
- 🏢 **部门管理**：树形结构部门管理，支持层级操作
- 📚 **字典管理**：系统字典配置，支持字典类型、值、描述管理
- 🔐 **权限控制**：基于路由的权限管理
- 📱 **响应式设计**：适配各种屏幕尺寸

## 技术栈

- **前端框架**：Vue 3
- **UI 组件库**：Element Plus
- **路由管理**：Vue Router 4
- **状态管理**：Pinia
- **构建工具**：Vite
- **HTTP 客户端**：Axios

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```
